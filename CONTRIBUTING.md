# Contributing to Udyami Manch

Thanks for helping. Keep it simple.

1. **Open an issue first.** Describe the bug or idea before writing code, so we agree on it.
2. **One change per pull request.** Do not bundle unrelated fixes.
3. **Open pull requests against `main`.**
4. **Match the existing style.** No reformatting or unrelated cleanups.
5. **Add tests** for new behaviour and make sure `npm test` passes.

A pull request should say what it changes, why, and how you tested it. Link the issue, for example `Fixes #12`.

By contributing you agree your work is released under the [AGPL-3.0](LICENSE).

Be kind. See the [Code of Conduct](CODE_OF_CONDUCT.md).
